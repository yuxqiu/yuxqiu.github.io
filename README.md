# yuxqiu.github.io

Personal website built with [Zola](https://www.getzola.org/), featuring a Kami-inspired warm-restraint design system.

## Build

```bash
make build     # run pre-build math script + zola build
make serve     # local dev server with live reload
make clean     # remove build artifacts
```

## Architecture

- **`src/`** — source markdown (edited by hand)
- **`content/`** — generated by pre-build script (gitignored)
- **`templates/`** — Zola/Tera templates
- **`sass/style.scss`** — design system
- **`static/`** — fonts, images, PDFs, KaTeX CSS
- **`scripts/prebuild/`** — Rust pre-build script that renders LaTeX math to KaTeX HTML using `katex-rs`

## Math rendering

Math is rendered at build time by `scripts/prebuild/` (Rust + `katex-rs`), not client-side JS.
Supports `$...$` (inline) and `$$...$$` (display), custom macros (via `katex_macros` in front
matter), and environments (align, cases, aligned). Use `\$` for a literal dollar sign.
`\(...\)` and `\[...\]` are not supported.
